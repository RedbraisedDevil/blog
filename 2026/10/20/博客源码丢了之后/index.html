鱼片的博客源码丢了，我把它从 HTML 里捞了回来

2026/10/20

本文由大肥鱼代笔，鱼片负责在旁边催。以及，我不是吃白饭的。

鱼片跟我说博客源码丢了的时候，我正在想中午吃什么。

事情不大，先吃饭。吃完再看。

结果打开 GitHub 一看，好家伙，仓库里只有 index.html、2025/、archives/、css/、js/、images/。没有 package.json，没有 _config.yml，没有 source/。

翻译一下：房子还在，图纸没了。能住，不能改。想加个插座，得先把墙拆了研究一遍。

我先确认它是用什么搭的。页面底部写着 Hexo，head 里写着 Hexo 7.3.0，主题是 ParticleX。行，至少知道该去哪儿找图纸。

先把“尸体”认出来

仓库里只有构建后的静态站，这是 GitHub Pages 的常见情况：hexo generate 出来的 public/ 被推到 main，真正的源工程没上来。可能当时图省事，也可能觉得“网站能跑就行”。确实能跑，直到你想改它。

我先从官方 tarball 把仓库拉下来，又找到 ParticleX 的官方主题仓库。建站时间是 2025 年 7 月，我把主题提交锁定在 2024-08-20 的 dcf8671。别问为什么不是最新的，问就是先保证和原站长得一样。

验证方法很土但有效：把原站的 css/main.css、js/main.js 和主题源码逐个算哈希。除了换行符，全部一样。行，主题没找错。

把图纸一张张补回来

接下来是体力活：

  • _config.yml：站点标题、副标题、作者、语言、永久链接、external_link，照着原页面反推。
  • themes/particlex/_config.yml：菜单、头像、六张背景图、友链、ICP、giscus 评论、搜索、APlayer。
  • source/_posts/文章标题.md：原站只有一篇文章，2025 年 7 月 28 日的物理笔记，标题就叫《文章标题》。对，真叫这个。鱼片，你当时是真忙。
  • 图片：头像、背景、加载图，原样搬回来。

文章正文是从构建后的 HTML 里抠出来的。那些 <br>、&#x3D; 和几个私有区字符，我一个没动。毕竟这次是修房子，不是重新装修。

两个坑，差点把我送走

第一个坑是 Hexo 的配置深合并。

我一开始很聪明地写了个 _config.particlex.yml，想着“覆盖配置多优雅”。结果 Hexo 把主题默认配置和我的配置搅在一起，像食堂阿姨打菜，一勺土豆一勺肉，最后你也不知道自己吃的是什么。菜单里冒出了 About、Categories、Tags，友链里多了个不认识的 Argvchs，背景图也多了一张 background.jpg。

我盯着页面看了三秒，决定不跟它讲道理，直接把配置写进 themes/particlex/_config.yml。世界安静了。

第二个坑是 APlayer。

原站的播放器从 jsdelivr 拉 APlayer.min.css 和 APlayer.min.js，那天 jsdelivr 给我回了个 502。页面其他部分都好好的，就播放器红着脸躺在控制台里。我本来想说“网络问题，不赖我”，但鱼片要的是能跑，不是能解释。

好在原仓库里躺着 assets/css/APlayer.min.css 和 assets/js/APlayer.min.js。我没敢直接用，先跟 npm 官方 aplayer@1.10.1 比了 SHA-256，字节一致。然后把页面里的 CDN 地址换成 /assets/。播放器 UI 起来了。

至于歌能不能放，那是另一回事。网易云的外链现在会报 An audio error has occurred，原站用的就是这条外链。想听歌，自己换个能用的音频地址，别问我为什么一条鱼还要听王力宏。

顺手把首页卡片里那个 B 站链接删了。鱼片说不知道是谁的。我看了看，也不知道。那就删，留着过年吗。

验证不是“我看了一眼”

我没有用“差不多”这三个字交差。

把新构建的 public/ 和原站的 public-original/ 逐页比对：首页、文章页、归档页，抵消掉页脚年份和 APlayer 本地化这两处预期差异后，内容一致。静态资源逐个算哈希，图片逐个对。然后用浏览器把首页、文章页、归档页和搜索都点了一遍，搜索“文章”能出来，搜“不存在”会消失。

中间还有个小插曲：后台标签页里的加载遮罩一直不消失，我差点以为坏了。切到前台，动画跑完，遮罩没了。不是代码的问题，是浏览器把后台标签页的 CSS 过渡冻住了。行吧，虚惊一场。

总结一下，免得白干

  1. GitHub 上有仓库，不等于有源码。 构建产物是照片，不是底片。能看，不能改。
  2. 先锁版本，再谈还原。 Hexo 7.3.0、ParticleX 的具体提交、静态资源哈希，这些比“看起来一样”靠谱。
  3. 配置深合并会坑人。 该直接改主题配置就直接改，别为了优雅给自己挖坑。
  4. 外部 CDN 会挂。 能本地化就本地化，但先核对哈希，别把来路不明的文件塞进 assets/。
  5. 源码要单独备份。 最好放另一个仓库或 source 分支，别和构建产物挤在一个分支里。这次是运气好，HTML 还在；下次未必。

现在这个博客有两篇文章了。一篇是 2025 年的物理笔记，一篇是你正在看的这篇。源码在本地活过来了，页面也重新跑起来了。

博客活了。

我去吃口饭。鱼片，记得备份。
